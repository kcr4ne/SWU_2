# R&E
---
## 수업 전에 알아두면 좋은 핵심 용어
- 연구 Reasearch : 답을 찾아가는 과정
- R&E Research & Education : 연구를 해보며 배우는 수업
- 가설 Hypothesis : "~일 것이다"라는 예측, 맞는지/틀린지 실험으로 확인할 수 있어야 함
- 변수 Variable : 실험에서 달라지거나 측정되는 값
- 선행연구 Prior Work : 주제와 관련해 이미 이루어진 연구, 우선적으로 찾아야 함
- 문헌조사 Literature Review : 선행연구를 찾고, 읽고, 정리하는 작업
- 재현성 Reproducibility : 똑같은 조건으로 다시 해도 같은 결과가 나오는 성질 (연구의 기본 조건)
- 논문 Paper / IMRaD : 연구 과정과 결과를 약속된 구조로(서론-방법-결과-논의) 정리한 문서

## 연구·프로젝트 공통의 5단계 사이클
1. 문제 정의
2. 가설/범위
3. 프로토타입
4. 검증
5. 공유
> ### 반복(iterate)과 되돌라아감이 자연스러운 과정
> 프로젝트는 한 번에 완성되는 직선이 아니라, 단계 사이를 왕복하며 다듬어지는 나선(spiral)에 가깝다

## 좋은 연구 주제의 5가지 조건: FINER
**F**easible : 해결 가능한가? | 보유한 시간·장비·데이터로 할 수 있어야 함<br>
**I**nteresting : 흥미로운가? | 나와 분야 모두에게 물을 가치가 있어야 함<br>
**N**ovel : 새로운가? | 기존 연구를 조금이라도 넘어서야 함<br>
**E**thical : 윤리적인가? | 타인에게 피해를 주지 않아야 함<br>
**R**elevant : 의미 있는가? | 실제 문제 해결이나 지식 확장에 기여해야 함<br>

# 연구 주제 선정 & 문제 정의
---
## 프로젝트 주제 프레임
> 우리는 {누구}를 위해 {어떤 보안 문제}를 해결하는 {어떤 결과}를 만든다

## 1차 자료 우선
### 권장
- Google Scholar : 학술 논문 통합 검색
- IEEE Xplore / ACM DL : 공학·보안 분야 핵심 DB
- USENIX Security · CCS · S&P · NDSS : 보안 Top 학회 Proceedings
- arXiv (cs.CR) : 프리프린트, 최신 연구
- DBpia · KCI : 한국 논문 데이터베이스
- NIST · CVE · MITRE ATT&CK : 표준·취약점·공격 기법 레퍼런스

### 주의하거나 보조용
- 개인 블로그 · 티스토리 : 근거 미확인, 복사 글 다수
- 위키피디아 : 출발점으로만, 인용 원문 찾기
- 뉴스 기사 : 사건 요약용, 기술 근거로는 약함
- AI 생성 요약 : 환각(hallucination) 가능, 반드시 원문 확인
- 연도 미표기·저자 불명 : 출처 신뢰도 낮음

# 문헌 조사 & 선행 연구 분석
---
## 논문을 효율적으로 읽는 3-Pass 전략
- 1st Pass : 스캐닝
  - 제목, Abstract, 서론, 결론, 그림/표 제목만 훓기
- 2nd Pass : 구조 이해
  - Method, Results를 그림 중심으로 읽기
- 3rd Pass : 깊이 읽기
  - 수식·알고리즘을 직접 재현하듯 따라가기

## 인용의 원칙과 표절 방지
### 인용의 3원칙
- 남의 말은 "따옴표: + 출처 표기
- 아이디어만 빌리는 경우도 반드시 인용
- 그림·표·데이터는 재사용 허가를 확인
- Paraphase해도 출처 남기기
- AI 생성 텍스트는 검토 없이 사용 금지

## 과학적 방법의 순환
관찰 - 가설 - 실험 - 분석 - 결론
> 결과가 가설과 다르면 -> 가설/설계 수정 -> 다시 실험

# 실험 설계 & 방법론
---
## 변수 설계
- 독립변수(v) : 내가 바꾸는 값
- 종속변수(DV) : 관찰하는 결과
- 통제변수(CV) : 고정해야 할 값

## 안전·윤리 기준 - 가능 · 주의 · 금지
### 가능
- 허용된 로컬/실습 환경
- 더미 데이터·가상 시나리오
- 방어·탐지·교육·분석 중심
- 공개된 샘플 데이터셋

### 주의
- 개인정보 최소화·익명화
- 실 서비스 유사 화면 배포 금지
- 위험 기능은 원리 설명으로 대체
- AI 생성 결과는 검토 후 사용

### 금지
- 실 사이트·서버·계정 공격
- 무단 스캔·로그인 시도
- 피싱 페이지·악성코드 배포
- 타인 개인정보 수집·게시

## 논문의 표준 구조: IMRaD
**I**ntroduction : 왜 이 연구가 필요한가? | 문제의 중요성 -> 기존 연구의 한계 -> 내 기여<br>
**M**ethods : 어떻게 연구했는가? | 실험 환경·데이터·알고리즘·변수·평가지표 타인이 재현 가능할 만큼 자세히<br>
**R**esults : 무엇이 관찰되었는가? | 표와 그래프로 객관적 제시, 해석 넣지 않기<br>
**a**nd** : Results와 DIscussion을 잇는 연결어<br>
**D**iscussion : 무엇을 의미하는가? | 결과 해석, 선행연구와의 비교, 한계, 향후 연구
